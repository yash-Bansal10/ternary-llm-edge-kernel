# 0. Abstract

The deployment of Large Language Models (LLMs) on resource-constrained Edge AI devices is severely limited by memory bandwidth bottlenecks. While extreme quantization techniques—such as BitNet and ternary precision {-1, 0, 1} networks [2], [7], [22]—drastically compress model weights, standard Neural Processing Units (NPUs) still incur a heavy "unpacking tax" [12]. This computational tax forces processors to decompress 2-bit weights back into INT8 or FP16 formats before executing standard Multiply-Accumulate (MAC) operations, introducing severe latency overhead. To eliminate this bottleneck, this research proposes a custom Bit-Serial Popcount architecture that executes vector dot-products natively on packed 2-bit ternary weights utilizing hardware-level `__builtin_popcount`, logical `XOR`, and `AND` gate intrinsics. The methodology leverages the open-source Gem5 Simulator [3] to perform strict, bare-metal hardware validation of an in-order ARM Edge processor. A 3-billion parameter model (Llama-Base-3B-BitNet) [1] was quantized and integrated via a custom PyTorch [4] C++ bridge [5]. Experimental results demonstrate that the proposed architecture successfully compresses the 1.4GB network footprint down to a 96MB binary payload (a 93% reduction). Furthermore, by entirely bypassing the decompression phase, the proposed Bit-Serial architecture achieved an absolute execution latency reduction of 21.68%. This performance scaling remained constant across multiple simulated hardware frequencies (500MHz to 2GHz). In conclusion, transitioning from traditional MAC arithmetic units to Bit-Serial logic gates offers a highly viable, energy-efficient pathway for achieving real-time LLM inference on untethered Edge devices, redefining extreme quantization as a foundational hardware execution paradigm rather than a mere storage-saving technique.
