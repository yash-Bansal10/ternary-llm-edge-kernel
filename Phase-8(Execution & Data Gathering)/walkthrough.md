## 🧪 Experimental Methodology Summary

This project successfully established a highly rigorous, end-to-end hardware testing pipeline to prove the viability of custom Edge AI chip designs:

1. **Weight Quantization & Packing (`pack_weights.py`)**
   - Successfully downloaded a 1.4GB FP16 HuggingFace Model (`model.safetensors`).
   - Quantized the model to Ternary {-1, 0, 1} format.
   - Packed the ternary values into highly dense bitplanes, compressing the model down to a **96MB binary file** (`packed_weights.bin`).
   - Mathematically verified that no data was lost during the bitwise packing process via a PyTorch round-trip integrity test.

2. **PyTorch C++ Integration (`setup.py` & `layer_test.py`)**
   - Rewrote the raw `__builtin_popcount` bit-serial C++ logic into a PyTorch-compatible module using `pybind11` (`poc_ternary_mac.cpp`).
   - Installed the custom C++ module into the supercomputer's Python kernel.
   - Flawlessly executed massive matrix multiplications by passing memory pointers between Python and C++, validating the architectural bridge.

3. **Bare-Metal Hardware Simulation (`Gem5`)**
   - Successfully compiled the Gem5 Hardware Simulator from source on an Ubuntu Supercomputer node.
   - Overcame massive network firewall blocks by manually injecting the `zlib` C++ source code into the kernel.
   - Overcame a literal typo within the Google Gem5 source code (`zlibVersion();`).
   - Cross-compiled the baseline and optimized C++ programs into native ARM binaries (`aarch64-linux-gnu-g++ -static`).
   - Configured a virtual ARM Edge AI Motherboard (`edge_config.py`) with a 1GHz clock speed and 512MB RAM.
   - Executed both ARM binaries in "Syscall Emulation" mode and recorded the exact clock cycles.
